# Decoders for Wazuh Custom Rules
Decoders were written for the rules below, but were overwritten by Wazuh's 
built-in decoders during log processing, so they were not used in the final product.
They are preserved here for educational purposes

# Crontab rule
Should extract the 'user' field from crontab modification events

# Schtasks
Should extract the 'taskName' field from sysmon Event ID 1 schtasks.exe events
