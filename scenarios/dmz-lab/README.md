# DVWA and Juice Shop web vulnerability focused scenarios hosted on a DMZ host
The goal of the scenario is to simulate a hosting of Web Application on a DMZ host, by using intentionally vulnerable Web Applications as DVWA and Jucie Shop

## Main activities
- Run multiple web-pentesting instances
- Perform correlating Incident Responses (with Incident Reports for each instance)
- Perform system and web-applications hardening

## Goals
- Develop a better understanding of Web-Applications deployment
- Maintanance of a Web-Hosting Application with focus on security
- Further deepening of Network Segmentation knowledge
- Gather first experiences with Web-Application hardening 
- Collect first experieces with pcap-Analysis and working with Wireshark
- Gather first experiences with Web-Application pentesting

## Used Technology
- Debian 13
- DVWA and JuiceShop Web-Applications
- Docker
- Wireshark
- Nginx
